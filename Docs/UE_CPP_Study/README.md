# UE C++: план на 24 недели (~3 ч/день)

Этот каталог — рабочая копия учебного плана: **не редактируйте** исходный файл плана в `.cursor/plans`, правки вносятся здесь при необходимости.

## Как пользоваться

- **Режим:** каждый день около **3 часов** (ориентир: 1 ч теория/доки, 1 ч упражнения, 1 ч практика в проекте).
- **Сквозная практика:** с **недели 9** ведите отдельный UE-проект **Training** и каждую неделю добавляйте одну маленькую фичу по теме недели. Подробности: [Training_Project_Checklist.md](Training_Project_Checklist.md).
- **Инструменты:** Visual Studio или Rider, документация Epic (Programming with C++), один курс/книга по C++ для фазы A.

## Критерий «уверенный мид» к концу 24-й недели

- В проекте Training: акторы/компоненты, подсистема с данными между уровнями, trace + interact, делегаты, таймер/timeline, UMG, минимум репликации или вводный GAS.
- Умеете объяснить, **где живёт состояние** и почему.
- Читаете геймплейный UE C++ (в т.ч. в этом репозитории) без постоянного поиска каждой строки.

Если пропускаете дни — не удваивайте нагрузку; лучше **сдвинуть неделю** и держать стабильные 3 ч/день.
