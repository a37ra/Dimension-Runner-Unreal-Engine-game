# Dimension Runner

Учебный проект игры на Unreal Engine 5.

## Описание

**Dimension Runner** — это динамичная игра, разработанная на Unreal Engine 5. Проект создан в образовательных целях для демонстрации навыков разработки игр на платформе Unreal Engine.Реализована лишь альфа версия, сделаная на коленке. База половины задуманных механик присутствует, что позволяет нарастить контент поверх этих механик.

## Основные возможности

- Геймплей межпространственного курьера который доставляет предметы по заказу
- Реализовано на C++ и Blueprints
- Оптимизированная архитектура для платформы Unreal Engine

## Требования

- **Unreal Engine 5.x** и выше
- **Visual Studio 2019** или более новая версия (для Windows)
- Компилятор C++17 или выше

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/a37ra/Dimension-Runner-Unreal-Engine-game.git
   ```

2. Откройте проект в Unreal Engine:
   - Запустите Unreal Engine
   - Нажмите "Open Project"
   - Выберите файл `.uproject` из папки проекта

3. Дождитесь загрузки и компиляции проекта

4. Нажмите кнопку "Play" для запуска игры

## Структура проекта

```
/Source          — исходный код на C++
/Content         — ассеты, карты и Blueprints
/Binaries        — скомпилированные файлы
```
