# Проект Training — сквозная практика (с недели 9)

Создайте **отдельный** пустой C++ проект Unreal Engine (имя, например, `Training`), не смешивая его с основной игрой, чтобы не бояться экспериментов.

## Создание (один раз, в конце недели 6 или начале 7)

1. Epic Games Launcher → Unreal Engine → нужная версия (желательно та же, что и у основного проекта).
2. Games → **New Project** → шаблон **Third Person** или **Blank** с **C++** (не только Blueprint).
3. Имя проекта: `Training`, путь — отдельная папка вне продакшн-репозитория или в отдельной ветке по желанию.
4. Убедитесь, что проект **компилируется** из Visual Studio / Rider без ошибок.

## Еженедельные мини-фичи (накопительно)

Отмечайте галочками по мере выполнения.

### Неделя 9 — компоненты

- [ ] Актор с `UActorComponent`, созданным в C++ (`CreateDefaultSubobject`).
- [ ] Параметр скорости/амплитуды в Details.
- [ ] Поведение «вращатель» или «пульсатор» на тестовом меша.

### Неделя 10 — ввод и trace

- [ ] Действие ввода (E или другое).
- [ ] `LineTrace` от камеры; `DrawDebugLine` на один кадр.
- [ ] При попадании в подходящий актор — вызов `UFUNCTION`.

### Неделя 11 — делегаты

- [ ] Компонент «здоровье» с multicast-делегатом `OnDead` (или аналог).
- [ ] Подписка: лог или UI реагирует на событие.

### Неделя 12 — таймеры и таймлайны

- [ ] Дверь/слайдер открывается по `UCurveFloat` и `FTimeline` за N секунд.

### Неделя 13 — подсистемы

- [ ] `UGameInstanceSubsystem` хранит число (очки/валюта).
- [ ] Два уровня в проекте; значение сохраняется при смене уровня (в рамках сессии).

### Неделя 14 — интерфейсы

- [ ] Интерфейс «Usable»; три разных актора реализуют его.
- [ ] Trace вызывает общий метод интерфейса.

### Неделя 15 — UMG

- [ ] Виджет с `BindWidget`; обновление по событию (не каждый кадр без нужды).
- [ ] HUD показывает здоровье из недели 11.

### Неделя 16 — физика

- [ ] `UPhysicsHandleComponent`: поднять и бросить простой меш.

### Неделя 17 — data-driven

- [ ] `UDataTable` со строками предметов; спавн по имени строки.

### Неделя 18 — анимация

- [ ] Один параметр из C++ в AnimBP (например скорость) влияет на blend.

### Неделя 19 — аудио / FX

- [ ] По событию геймплея — звук + простой Niagara или постэффект (минимум).

### Неделя 20 — качество

- [ ] Убрать один лишний `Tick`, заменить таймером или событием; зафиксировать в комментарии/логе почему.

### Неделя 21 — репликация

- [ ] Одно реплицируемое свойство + `OnRep` меняет визуал или UI.

### Неделя 22 — GAS **или** репликация (одна ветка)

- [ ] Либо минимальный ASC + один атрибут + простой GameplayEffect.
- [ ] Либо реплицируемый массив struct с условиями репликации (обзорно).

### Неделя 23 — сборка

- [ ] Сборка **Shipping** Training; запуск `.exe` вне редактора.

### Неделя 24 — портфолио

- [ ] README к Training: как открыть, управление, что сделано.
- [ ] Короткое видео (2–3 мин) или скринкаст с пояснением одного класса.

## Заметки

- Коммитить в Git: не добавляйте `Binaries/`, `Intermediate/`, `Saved/` (используйте `.gitignore` для UE).
- Если Training только локально — достаточно zip-бэкапа раз в месяц.
