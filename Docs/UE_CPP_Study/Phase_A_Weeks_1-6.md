# Фаза A — C++ база без UE (недели 1–6)

**Бюджет:** ~3 ч/день, ~21 ч/неделя.  
**Ресурс:** один учебник или курс по C++ на ваш выбор (недели 1–6).

---

## Неделя 1 — Среда и первые программы

| День | Тема (3 ч) |
|------|------------|
| 1 | Установка компилятора/IDE, первый `main`, сборка Debug/Release, где лежит exe, что такое ошибка линковки (на уровне «вижу в тексте»). |
| 2 | Типы: `int`, `float`, `bool`, `char`; объявление переменных; арифметика; `std::cout` / `std::cin`. |
| 3 | Условия `if/else`, `switch`; сравнения; логические `&&` `||` `!`. |
| 4 | Циклы `for`, `while`; вложенность; осторожно с off-by-one. |
| 5 | Функции: объявление/определение, параметры, `return`; область видимости. |
| 6 | Массивы фиксированного размера; простые задачи на циклы по массиву. |
| 7 | Недельный **мини-итог**: консольная «задачка на 100 строк» (меню + цикл), без классов. |

**Итог недели:** программа с меню и циклом, без ООП.

---

## Неделя 2 — Указатели и ссылки (минимум для UE)

| День | Тема |
|------|------|
| 1 | Стек vs куча на концептуальном уровне; что такое адрес; оператор `&`. |
| 2 | Указатели `*`, `->`; `nullptr`; разыменование; типичные ошибки. |
| 3 | Ссылки `&` у параметров; отличие ссылки от указателя (когда что читают в UE-коде). |
| 4 | Динамическая память `new`/`delete` (только чтобы понять идею; в UE почти не пишут руками). |
| 5 | `const` у переменных и параметров; const-указатели vs указатель на const (поверхностно). |
| 6 | Передача в функцию: по значению / по ссылке / указатель; мини-задачи. |
| 7 | Итог: 2–3 задачи из списков (разворот, поиск min/max), только функции + массивы. |

**Итог недели:** уверенное чтение сигнатур с указателями и ссылками.

---

## Неделя 3 — Классы и ООП-ядро

| День | Тема |
|------|------|
| 1 | `class`, `public/private`, методы, `this`. |
| 2 | Конструкторы; инициализация полей; деструктор (идея). |
| 3 | Инкапсуляция: геттеры/сеттеры; зачем не светить поля. |
| 4 | Наследование; `virtual` и переопределение; полиморфизм на одном маленьком примере. |
| 5 | Чистые виртуальные / абстрактный класс (концепт, без углубления). |
| 6 | `enum class` vs старый `enum` — в UE почти везде `enum class`. |
| 7 | Итог: класс `Inventory` в консоли (добавить/удалить предмет по имени), без STL-containers пока или минимум `std::string`. |

**Итог недели:** один законченный класс предметной области в консоли.

---

## Неделя 4 — STL минимум (то, что всплывёт рядом с UE)

| День | Тема |
|------|------|
| 1 | `std::string`: конкатенация, `c_str()` (зачем при API на C-строках). |
| 2 | `std::vector`: push/pop, размер, итерация range-for. |
| 3 | `std::map` или `unordered_map`: ключ-значение; когда map уместен. |
| 4 | Итераторы на уровне «range-for достаточно». |
| 5 | Алгоритмы: `sort`, `find` — один раз руками вызвать. |
| 6 | Исключения: `try/catch` — только знакомство; в геймплее UE чаще `ensure/check`. |
| 7 | Итог: переписать инвентарь на `vector`/`map`, маленькая CLI. |

**Итог недели:** инвентарь на контейнерах STL.

---

## Неделя 5 — Заголовки, раздельная компиляция, пространства имён

| День | Тема |
|------|------|
| 1 | `.h` vs `.cpp`; include guards / `#pragma once`. |
| 2 | Декларация vs определение; forward declaration (идея). |
| 3 | Пространства имён `namespace`; `using` — осторожно. |
| 4 | Сборка нескольких файлов в один exe; что такое единица трансляции. |
| 5 | Макросы препроцессора — грубое знакомство (в UE их много). |
| 6 | Условная компиляция `#ifdef` — зачем в кроссплатформенном коде. |
| 7 | Итог: разбить недельный класс на `.h/.cpp`, чистая сборка. |

**Итог недели:** проект из нескольких `.h/.cpp`, собирается без ошибок.

## Неделя 6 — Закрепление C++ перед UE

| День | Тема |
|------|------|
| 1–2 | Повтор: указатели + классы — смешанные задачи (список указателей на объекты в `vector` упрощённо). |
| 3 | Чтение чужого маленького C++ проекта (GitHub, 5–10 файлов): найти `main`, классы, поток выполнения. |
| 4 | Написать **диздок на 1 страницу** для своей тренировочной игры (что за Training-проект будет через 10 недель). |
| 5–6 | Мини-проект: текстовая игра или симулятор с 3+ классами и раздельной компиляцией. |
| 7 | Установить **Unreal Engine 5.x**, создать пустой проект C++, убедиться что собирается; прочитать обзор **модулей** и **Target.cs** без глубины. |

**Итог недели:** мини-проект на C++ + рабочий пустой UE C++ проект.
